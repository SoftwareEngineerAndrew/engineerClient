# ADM

Advanced Dungeons Mod: an [Odin](https://modrinth.com/mod/odin) addon for Hypixel SkyBlock dungeons.

## Download

| Minecraft | Download |
|---|---|
| **26.3** | **[ADM-26.3.jar](https://github.com/undonecoffee/adm/releases/download/release-main/ADM-26.3.jar)** |
| 26.2 | [ADM-26.2.jar](https://github.com/undonecoffee/adm/releases/download/release-26.2/ADM-26.2.jar) |
| 26.1.2 | [ADM-26.1.2.jar](https://github.com/undonecoffee/adm/releases/download/release-26.1.2/ADM-26.1.2.jar) |

Each link is always the newest build for that version. You don't need the source code.

## Install

Put the jar in your `mods` folder, along with:

- [Fabric Loader](https://fabricmc.net/use/installer/)
- [Fabric API](https://modrinth.com/mod/fabric-api)
- [Fabric Language Kotlin](https://modrinth.com/mod/fabric-language-kotlin)
- Odin: [from Modrinth](https://modrinth.com/mod/odin) for 26.2 and 26.1.2. Odin for 26.3 isn't
  released yet; ADM 26.3 is built against the test build from
  [Odin's 26.3 pull request](https://github.com/odtheking/OdinFabric/pull/164).

ADM was called Engineer Client before. Updating from it: delete the old `engineerclient` jar from `mods`; your settings and saved data move over by themselves the first time ADM starts.
