# EngineerClient

An [Odin](https://modrinth.com/mod/odin) addon for Hypixel SkyBlock dungeons.

## Download

| Minecraft | Download |
|---|---|
| **26.3** | **[EngineerClient-26.3.jar](https://github.com/undonecoffee/EngineerClient/releases/download/release-main/EngineerClient-26.3.jar)** |
| 26.2 | [EngineerClient-26.2.jar](https://github.com/undonecoffee/EngineerClient/releases/download/release-26.2/EngineerClient-26.2.jar) |
| 26.1.2 | [EngineerClient-26.1.2.jar](https://github.com/undonecoffee/EngineerClient/releases/download/release-26.1.2/EngineerClient-26.1.2.jar) |

Each link is always the newest build for that version. You don't need the source code.

## Install

Put the jar in your `mods` folder, along with:

- [Fabric Loader](https://fabricmc.net/use/installer/)
- [Fabric API](https://modrinth.com/mod/fabric-api)
- [Fabric Language Kotlin](https://modrinth.com/mod/fabric-language-kotlin)
- Odin: [from Modrinth](https://modrinth.com/mod/odin) for 26.2 and 26.1.2. Odin for 26.3 isn't
  released yet; EngineerClient 26.3 is built against the test build from
  [Odin's 26.3 pull request](https://github.com/odtheking/OdinFabric/pull/164).
