# ChatTriggers originals

The team's own ChatTriggers modules, copied from `undonecoffee/allModules` (`made by us/`,
last commit 2025-06-29 "ENGINEER"). Reference only — nothing here is built or shipped.
They are what the Kotlin splits were ported from, so a question about "how it used to look"
is answered here rather than from memory.

| File | What it is |
|---|---|
| `EngineerClient_features_EngineerSplits.js` | The run's splits: Pace, Open, Blood, Portal, Enter, Maxor, Storm, Terms, Goldor, Necron, Animation. |
| `EngineerClient_features_EngineerSubSplits.js` | The 25-step boss breakdown, grouped under bold phase headers. |
| `EngineerClient_data.js`, `_index.js`, `_features_EngineerClient.js` | Its config store and entry point. |
| `EngineerClient_dev-organization-temp_subSplits.txt` | The sub-splits file's own running order. |
| `BloodTimer_index.js`, `_config.js` | Blood move *prediction* — not a split. |
| `splitsBUTBAD.js` | The older one-line-each clear splits it replaced. |
