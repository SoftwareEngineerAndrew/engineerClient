# Odin features in the F7 boss vs what p3sim feeds them

Odin 0.3.4 (`38ddc1b`, same as `libs/Odin-0.3.4-26.1.jar`; later commits only touch LeapMenu/LeapMap).
Gating background is in `odin-gating.md`. Here, "chat" means `MessageEvent.Chat` (system chat with `noControlCodes`),
so the sim's `§`-coloured chat lines are fine as long as the plain text matches.

The bridge (`P3Sim.bridge`) sets `currentArea = Island.Dungeon`, `isInSkyblock`, `floor = F7`, `inBoss = true`
and the teammates (bots get `entity = null`). `Fight.tick` sends `ClientboundPingPacket(serverTick)` every tick,
before the phase tick, so `TickEvent.Server` fires. Because the area is Dungeon rather than SinglePlayer:
`getF7Phase()` needs floor + inBoss (they're set), Etherwarp's client-side SP teleport is off, and
the "Account For Server Lag" first-click protection is live.

## Important: the `§`-in-literal trap
`Component.literal("§cFoo").string` is `"§cFoo"`. Odin strips codes from **chat**, but **not** from entity
names or item hover names. Every sim entity and item name that Odin compares exactly must be styled
with `withStyle(ChatFormatting...)`, not given `§` codes. That causes three of the mismatches below.

## Fixes, most important first
1. **Leap heads:** `SimItems.kt:533`, replace `Component.literal("§a${b.name}")` with `Component.literal(b.name).withStyle(ChatFormatting.GREEN)`. Odin's leap-menu click currently fails the name compare.
2. **Status armor stands** (`Station.kt`): style the names instead of using `§` codes. This fixes Inactive Waypoints labels (all show "Lever") and Arrows Device's `"Active"` entity completion.
3. **Terminal ding:** `GoldorPhase.kt:163`, play PLING at volume 8f, pitch 4.047619f so Odin's Terminal Sounds can cancel or replace it.
4. **Completion subtitle:** also send each `X activated a terminal! (n/7)` as a subtitle (empty title). This turns on Terminal Titles and matches Hypixel's on-screen notice.
5. **Splits:** send `Starting in 1 second.` before the first boss line; add Necron `All this, for nothing...` at the end of P4.
6. Verify tick alignment: Storm pad crush vs Odin's 20-tick loop (sim checks at t%20==19), the Goldor start timer (104 from Storm death vs the sim's 102 line delay), and Necron drop 60 ticks after `I'm afraid…`.
7. Optional fidelity: bots as Player entities (Leap Map, class glow), helmet mask items, FIREWORK beam particles, action bar, Phoenix 80-tick i-frames.
